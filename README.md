FS22 → FS20 Mod Converter (protótipo)

Como usar:
1. Extraia o ZIP no seu dispositivo.
2. Abra index.html num navegador moderno ou hospede os arquivos estáticos.
3. É necessária conexão com a internet para carregar JSZip e Three.js via CDN.

Recursos:
- Lista arquivos dentro de mods ZIP.
- Inspeciona arquivos de texto como XML e I3D.
- Exporta novamente o conteúdo ZIP sem alterar a compatibilidade.
- Visualiza arquivos GLB/GLTF compatíveis.

Limitações:
- Não converte automaticamente mods FS22 para FS20.
- Não carrega I3D/SHAPES nativamente; é necessário implementar um parser/conversor específico.
