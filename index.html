FS22 → FS20 Mod Converter

Importar ZIP, analisar arquivos e visualizar modelos compatíveis

📦 1. Importar mod

Aguardando arquivo. Para analisar um mod completo, selecione o ZIP original.

🗂️ 2. Arquivos encontrados

Nenhum mod carregado.
Os arquivos aparecerão aqui.

🧊 3. Visualizador 3D

Este visualizador carrega GLB/GLTF. Os modelos I3D/SHAPES do FS22 precisam de um conversor específico antes de aparecer aqui como modelo real.

⬇️ 4. Exportar

Gera um novo ZIP preservando os arquivos internos. Isso não garante compatibilidade com o FS20 nem converte automaticamente modelos e XML.

ℹ️ Limitações desta versão

• Lê a lista de arquivos de um ZIP.

• Permite inspecionar XML, I3D e outros arquivos de texto.

• Exporta novamente o ZIP.

• Visualiza modelos GLB/GLTF; não interpreta I3D/SHAPES nativamente.

Requer internet para carregar JSZip e Three.js via CDN.
